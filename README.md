# AI Agent Book 学习笔记

这是我阅读《深入理解 AI Agent：设计原理与工程实践》时整理的分章学习笔记。

仓库围绕 **Agent = LLM + 上下文 + 工具** 这一主线，记录每章的重要概念、工程范式、代码理解、常见误区与章末复习问题。后续将随着阅读进度持续补充，并尝试把适合复用的方法进一步提炼成 Agent Skills。
